* Due to ADO API limitations:
  * User and time fields' impersonation is not supported.
  * Synchronization of Delivery Plan is only supported for team foundation server 2018 & above.
  * Criteria is only supported on the ID of an delivery plan entity.
* The Team entity is supported only as a reference field to be mapped.
* For using the Delivery Plan entity, the Team Foundation Server instances below version 2022 must have the Delivery Plan Market Place Extension installed.
  * Link to the extension: [Delivery Plan Market Place Extension](https://marketplace.visualstudio.com/items?itemName=ms.vss-plans)
